# Competitor Research — Wispr Flow

Source: https://docs.wisprflow.ai/ and https://wisprflow.ai/ (crawled 2026-08-26)

Wispr Flow (by Wispr AI, founded 2021, ~$81M funding) is an AI dictation tool covering Mac, Windows, iOS, and Android. System-wide dictation in every app, AI cleanup, Command Mode, and a Notetaker. Subscription: Free + Pro ($12–15/mo) + Enterprise.

## Platforms
- macOS 12+, Windows 10 64-bit+, iOS 18.3+, Android 13+ (beta). Only major tool on all four platforms.
- Cross-device sync of dictionary/styles/snippets/settings.

## Core dictation
- System-wide into any app; marketed 4x faster than typing.
- Push-to-talk and hands-free (double-press).
- Clipboard fallback when no field focused.
- Scratchpad (desktop/iOS); whisper-quiet dictation.
- History + dictation stats (words, wpm, streak).

## AI / LLM text processing
- Filler-word removal, auto punctuation/formatting, self-correction handling.
- Context-aware formatting adapts to the active app.
- Advanced AI thinking models (Pro).

## Editing & voice commands
- Command Mode (Mac/Win, paid): speak instruction to transform selected text.
- Transforms (Beta): up to 9 slots, 5 built-in rules + 5 custom instructions, writing samples, Auto Apply After Dictation, Diff view.
- Polish (iOS): 5 built-in + custom instructions.

## Personalization
- Personal dictionary (auto-adds corrections; team dictionary on paid).
- Snippets (voice shortcuts): trigger ≤60 chars, body ≤4,000 chars; desktop/iOS/Android.
- Flow Styles / tone per app category (Formal/Casual/Excited); English-focused.
- Context Awareness: reads limited on-screen text + active app for proper-noun/style matching.

## Wispr Notetaker (meeting capture)
- On-device recording, no bot joins; works with any meeting app + in-person.
- Live transcript; re-reads recording post-meeting for sharper final + speaker labels.
- Speaker identification by name; Flow Summaries; Ask Wispr (chat, Mac only) across meetings/notes/calendar/apps.
- "What did I miss?"; pre-read meeting briefs; meeting detection & reminders.
- Calendar (Google only), connectors (Gmail/Slack/Notion), share by link/email.
- Mac-only today; Windows coming soon; included on Free + Pro.

## MCP integration
- Read-only MCP server exposing Notetaker data to Claude/ChatGPT/Cursor/VS Code.
- Quick-connect cards; same URL across tools. Mac desktop only.

## Languages
- 100+ marketed; 104–105 dictation languages; 12 "confident".
- Auto language detection + code-switching; language picker one click.
- Styles/Context English-focused; Notetaker English-first.

## Privacy & security
- Privacy Mode (no retention/training); opt-out of model training.
- Zero data retention agreements with providers.
- HIPAA (all plans), SOC 2 Type II, ISO 27001.
- Enterprise: SSO/SAML/SCIM, MDM, audit logs, admin controls.

## Pricing
- Free $0 (2,000 words/week desktop; unlimited Android; Notetaker + MCP).
- Pro $12/mo annual / $15/mo monthly (unlimited dictation, thinking models, more meetings).
- Enterprise custom. Students 50% off; 40% accessibility discount; Android free at launch.

## Integrations / supported apps
- Dictation: any text field (Gmail/Slack/Notion/code editors/AI tools).
- Notetaker connectors: Google Calendar, Gmail, Slack, Notion.
- MCP-connected: Claude, ChatGPT, Cursor, VS Code.
- Meeting platforms: Zoom, Meet, Teams, Slack huddles, Discord, browser, phone, in-person.

## Accessibility
- Hands-free tool for motor impairments, Parkinson's, RSI, dyslexia, ADHD, stuttering, visual impairments; 40% disability discount.

## Developer
- No public REST API; developer surface is the read-only remote MCP server (URL-based, no keys).
- Up to 4 shortcuts per action, mouse buttons 4–10.

## Known limitations
- Cloud-only (no offline). Screenshot/context capture raises privacy concerns. Trustpilot ~2.7/5. Windows app heavy (~800 MB RAM). Command Mode/Transforms/Context gated to paid or Mac/Win. Notetaker Mac-only.
