## 4. CI failure triage — the procedure that worked

### 4.1 Get the failing job's details

```bash
gh pr checks 31                          # overall matrix
gh api repos/maus-inc/mausVoice/actions/runs/<RUN_ID>/jobs \
  --jq '.jobs[] | {name, conclusion, steps: [.steps[] | {name, conclusion}]}'
```

### 4.2 Pull logs when `gh run view --log-failed` fails with EOF

```bash
# 1. Resolve the signed log URL (curl prints only headers; the Location
#    header is the Azure blob URL):
TOKEN=$(gh auth token)
JOB_ID=<job-id-from-4.1>
curl -s -o /dev/null -D - -H "Authorization: Bearer $TOKEN" \
  "https://api.github.com/repos/maus-inc/mausVoice/actions/jobs/$JOB_ID/logs" \
  | grep -i '^location:' | sed 's/^[Ll]ocation: //' | tr -d '\r' > /tmp/logurl.txt

# 2. Fetch the blob URL with whatever HTTP client has network access
#    (the sandbox that produced this handoff could reach the blob only via
#    a page-fetching tool; curl sometimes failed with SSL_ERROR_SYSCALL —
#    try both).
```

Then read the log from the END backwards: the first `error[...]` after the
last `Compiling mausVoice ...` line is the actionable one; downstream
errors (tauri macro trait bounds, `__cmd__*` noise) are usually cascade.

### 4.3 Failure signature → cause → fix (all previously encountered)

| Signature | Cause | Fix location |
|---|---|---|
| `failed to select a version for 'sysinfo' ... feature 'system' does not exist` | invalid feature spec | `apps/desktop/src-tauri/Cargo.toml` — must be plain `sysinfo = "0.30"` |
| `duplicate serde attribute 'default'` | leftover attr after field removal | `domain/preferences.rs` — exactly one `#[serde(default)]` per field |
| `cannot find '__cmd__X' in commands` | a `#[tauri::command]` fn was deleted but still registered in `app.rs` | restore the fn or unregister it (see audit below) |
| `mismatched types: expected AppHandle, found &AppHandle` | `app.handle()` returns `&AppHandle` | call `.clone()` |
| `this function has too many arguments (8/7)` | clippy on `draw_paused` / `draw_edge_gradient` | `#[allow(clippy::too_many_arguments)]` (pattern already used by `draw_waveform`) |
| `variable does not need to be mutable` | `unused_mut` | remove `mut` |
| orphaned `.map(\|v\| v != 0) .unwrap_or(false),` lines in a struct literal | row-map field deleted without its tail | `db/preferences_queries.rs` |
| Integration test: `Test timed out in 180000ms` preceded by `groq llm usage: {... reasoning_tokens: ...}` | **Groq rate-limit flake, not code** — do not "fix" code | re-run (§4.6) |
| `#[tauri::command]` trait-bound cascade (`IpcResponse`, `CommandArg` not satisfied) | a serde derive broke upstream | fix the derive error first; cascade disappears |

**Audit commands that kept the command registry honest:**

```bash
# Every #[tauri::command] fn must be registered in app.rs and vice versa:
grep -o 'pub \(async \)\?fn [a-z0-9_]*' apps/desktop/src-tauri/src/commands.rs
grep -o 'crate::commands::[a-z0-9_]*' apps/desktop/src-tauri/src/app.rs
```

## 8. Hard rules — do not regress these

1. **No Tailwind, no `cn()`, no standalone `motion` package.** MUI v7 +
   `framer-motion` only. The pasted shadcn/ReactBits designs were already
   adapted; do not "simplify" them back into raw Tailwind.
2. **Do not re-introduce** mausVoice Cloud, enterprise, pricing/payment, or
   trial UI. Firebase **Auth + RTDB (remote devices)** stay. If anything
   references them, delete the reference, not the removal.
3. `scripts/ci/pr28-contracts.test.mjs` now encodes the NEW reset-position
   API (`notify_reset_position(app, strategy)`, `InMessage::ResetPosition {
   strategy }`, `invoke("reset_pill_position", { strategy })`). Keep those
   assertions in sync with any further IPC change; 15/15 must pass.
4. Migration `071` intentionally spells the cloud literal as
   `char(99,108,111,117,100)` to satisfy Sonar S1192 — do not "clean it
   back" to three `'cloud'` literals.
5. Migrations `071..074` are registered in
   `apps/desktop/src-tauri/src/db/mod.rs` with versions 71..74; the next
   migration number is **075**. Never renumber or edit an already-shipped
   migration; add a new one.
6. Pill geometry/animation math shared by the three pill crates lives in
   `packages/rust_pill_shared/src/lib.rs` (`ring_dash_period`,
   `ring_dash_offset`, `ring_dash_is_on`, `pill_radius` cap formula). Keep
   the three renderers byte-for-byte consistent in their geometry.
7. `pill_radius(pill_w, pill_h, inflate)` must evaluate to the old 16px
   clamp when `inflate == 0` — idle/expanded look is a hard regression test
   (QA §7.3).
8. Phase serialization on the pill pipe: phase messages carry `seq`
   (`#[serde(default)]` on the field); all three pills ignore stale seq.
   Any new phase sender must go through the same seq channel.
9. Never commit: `node_modules`, `dist`, `target`, log files, or the
   temporary diagnostic workflow. Never force-push.
10. Version bumps: desktop + windows-installer are already `0.1.6` in
    `package.json`, `tauri.conf.json`, `Cargo.toml`, `Cargo.lock`. If any
    file says otherwise, restore `0.1.6` (except third-party crate versions
    in `Cargo.lock`, which are unrelated).
