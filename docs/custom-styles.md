# Custom styles

> Maintained page: [Custom styles](https://maus-inc.github.io/mausVoice/docs/using-mausvoice/custom-styles/).

Create a style from the Writing styles page. Give it a name and describe the transformation in the prompt field. Optional structured guidance can specify a category, desired output length, and a short example input/output pair.

Structured fields are stored locally with the style and are appended to the post-processing system prompt only when present. Leaving them blank preserves the existing free-form behavior.
