# When a green test does not establish the behavior

**Decision, 2026-11-17:** keep judgment in [the reviewer standards](../CODING_STANDARDS.md). Put repeatable failures at the boundary that can actually observe them. The most useful change is not another instruction to "test thoroughly". It is to make a missing tool result, extra HTTP request, stale review, or surviving microphone distinguishable from success.

## Sources and coverage

Method: Matt Pocock's AI Hero [`retro`](https://github.com/mattpocock/skills/blob/5863806dd4e15c63174bee4e7515a4256792ecfa/skills/engineering/retro/SKILL.md), including its [`writing-for-agents`](https://github.com/mattpocock/skills/blob/5863806dd4e15c63174bee4e7515a4256792ecfa/skills/productivity/writing-for-agents/SKILL.md) reference. Start from primary records, inspect existing checks, separate implementation from review, and rank changes by consequence. This is a retrospective of review evidence, **not** a count of unique bugs, author performance, or a claim to have manually adjudicated every comment.

The [coverage ledger](merged-review-coverage.csv) has one row for every merged PR, ordered by `merged_at` rather than PR number, with an example source link per row. - Retrieved all pages for 300 accessible PRs, 12,694 inline comments and 6,811 submitted reviews. Of 3,779 issue-discussion records, 3,773 belonged to PRs. Matched records by numeric PR ID, not title or branch. The merged subset above is the historical denominator; open/closed-unmerged work is not silently counted as shipped.
- 132 merged PRs had inline comments, 153 had submitted reviews, and all 174 had PR discussion. Only **510** merged-PR submitted reviews had nonempty bodies. An inline reply saying "fixed", a bot summary quoting its own finding and an approval are not three independent observations. #317 alone accounts for 100 thread starters and 153 replies.
- Searched the corpus by path and recurring mechanisms (ownership, migration, retry, private data, layout, test oracle and workflow scope); read examples from each merge month against implementations, packages, migrations or tests. Included contrary advice and cases with no substantive review. This is a coverage index plus qualitative synthesis, not a classifier's prevalence estimate. No raw review exports, credentials or provider output are stored here.
- To reproduce: page `gh api --paginate 'repos/maus-inc/mausVoice/pulls?state=all&per_page=100'`, `pulls/comments?per_page=100`, `issues/comments?per_page=100` and, for **each** PR, `pulls/<number>/reviews?per_page=100` under the same repository. Index IDs, keep records with non-null PR `merged_at` on or before the cutoff above, separate `in_reply_to_id` and blank review bodies, then group by UTC merge month. Later comments on those PRs can change a rerun's counts.

## Lessons from the reviews, highest consequence first

| Risk | What the primary evidence changes about review |
| --- | --- |
| **Capture continues, or a late result is applied to the wrong session** | [#211, cancellation inside a batch](https://github.com/maus-inc/mausVoice/pull/211#discussion_r4106349853) distinguishes rejecting the caller from observing already-started work. [#322, discard racing a failed stop](https://github.com/maus-inc/mausVoice/pull/322#discussion_r4516358434) and [#317, restored recorder](https://github.com/maus-inc/mausVoice/pull/317#discussion_r4532100082) show why an idle flag is the wrong oracle. [#334's implementation and test](https://github.com/maus-inc/mausVoice/pull/334#issuecomment-6792169567) close the loop at the handle. Trace ownership through the failing teardown and into the next generation (CS01). |
| **Private or billable data leaves on a secondary path** | [#164, logging chat text](https://github.com/maus-inc/mausVoice/pull/164#discussion_r3938185648) correctly identified disclosure, but truncating text as suggested still discloses text. [#187, opt-in for billable keyterms](https://github.com/maus-inc/mausVoice/pull/187#discussion_r3967440264) distinguishes dictionary consent from provider consent. [#284, a queued write after private mode ends](https://github.com/maus-inc/mausVoice/pull/284#discussion_r4201216461) adds a time dimension. Check the actual sink and both sides of the transition (CS03). |
| **Data disappears while both sides type-check** | [#80, generated command without generator registration](https://github.com/maus-inc/mausVoice/pull/80#discussion_r3809277931); [#128, applied migration missing from history](https://github.com/maus-inc/mausVoice/pull/128#discussion_r3832758495); [#164, failed DB delete but successful UI removal](https://github.com/maus-inc/mausVoice/pull/164#discussion_r3937901006); [#282, stale whole-row write](https://github.com/maus-inc/mausVoice/pull/282#discussion_r4286264908). A round trip needs the writer's actual bytes, the old row, and the failure case. Do not replace the database with a map that has a different delete contract (CS02). |
| **Retries multiply or disguise failure** | [#109, discovery bypassing the native fetch transport](https://github.com/maus-inc/mausVoice/pull/109#discussion_r3818372975) and [#221, account-wide errors sent to another model](https://github.com/maus-inc/mausVoice/pull/221#discussion_r4108499499) are not model-name lint problems. Count attempts below the real client. Rejecting an unusable cleanup and returning raw text are different outcomes (CS04). |
| **A test passes because a different path supplied the answer** | [#73, a capacity test that never filled the capacity](https://github.com/maus-inc/mausVoice/pull/73#discussion_r3809339134); [#221, fallback guard masks abort](https://github.com/maus-inc/mausVoice/pull/221#discussion_r4107775197); [#238, exported constants instead of rendered button](https://github.com/maus-inc/mausVoice/pull/238#discussion_r4165035713); [#288, a context menu that need never open](https://github.com/maus-inc/mausVoice/pull/288#discussion_r4454551510). Two recommendations on [brace walking](https://github.com/maus-inc/mausVoice/pull/184#discussion_r3951743173) / [balancing braces](https://github.com/maus-inc/mausVoice/pull/184#discussion_r3952526960) improve neither the observation nor the oracle. Execute the decision; keep source comparison for actual byte-level contracts (CS07). |
| **A build or visual claim holds for only one consumer** | [#7, localize the control's accessible name too](https://github.com/maus-inc/mausVoice/pull/7#discussion_r3744651688); [#55, integrity on the existing-file path](https://github.com/maus-inc/mausVoice/pull/55#discussion_r3790381830); [#280, two theme defaults before and after mount](https://github.com/maus-inc/mausVoice/pull/280#discussion_r4178954655); [#313, same locked skill but Windows separators](https://github.com/maus-inc/mausVoice/pull/313#discussion_r4407462834). Test a cache hit and a cold start; trace the native target, keyboard focus, accessible label and real hit box, not just the nominal asset (CS05, CS06). |
| **Green CI judged the wrong thing** | [#41, omitted workspace and patch inputs](https://github.com/maus-inc/mausVoice/pull/41#discussion_r3783800831) and [#316, the PR judging its own body](https://github.com/maus-inc/mausVoice/pull/316#discussion_r4480848267) invalidate a green check without changing the feature. A [bot declined #317's large diff](https://github.com/maus-inc/mausVoice/pull/317#issuecomment-6683051753). A visible checkbox is not a current-head check; an empty report is not a full-diff review (CS08). |

## Test audit: two snapshots, not a merge into main

The working base is `arena/0.1.6-consolidation` at `b1acb431`. `main` at `bfbf88a6` diverged from it at `3a37f922`: 7 main-only and 1,183 consolidation-only commits. The main-only commits change documentation or review configuration. `git ls-tree -r` and `git show` were used on **both** tips; neither switching branches nor merging these histories is necessary to inspect them.

| Tracked JS/TS test/spec files before this change | Desktop | Preview | Voice AI | Agent | Utilities | CI scripts | Total |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `main` | 30 | 0 | 1 | 0 | 1 | 2 | 34 |
| Consolidation | 369 | 4 | 38 | 1 | 6 | 23 | 441 |

The inventory covers `apps`, `packages`, `scripts` and `patches`, counting `*.{test,spec}.{ts,tsx,js,jsx,mjs,cjs}`. A separate `git grep` for Rust test attributes found 39 Rust files on main and 144 on consolidation. These are files, not executions. The source-read screening step also selects valid fixture, prompt-sync and generated-file checks: a `readFileSync` hit alone is **not** a finding.

- On **both** tips, WebDriver's `onPrepare` accepted a stale executable after the fixture's npm build exited 17. With the old consolidation config, the [regression](../apps/desktop/scripts/webdriver-prepare.test.mjs) expected 17 and got 0. The repaired hook propagated 17 even with the old file present; the successful control exited 0 and wrote new bytes. This establishes build-error propagation, not that every successful build produces a fresh binary or that its window renders.
- On **both** tips, the bootstrap WebDriver spec accepted a root child such as the loader. The stability integration test could accept nonempty raw input from fallback. A longer polling timeout on consolidation did not make either oracle better. Main's small Groq suite tests request mapping at the SDK method, not transport attempt count; the mapping check is worth keeping.
- On consolidation, traced the JS repo to the Rust API-key queries and migration 063 to real SQLite with foreign keys enabled. The parent delete took message count from 1 to 0. The chat fake previously kept the orphan as the expected result. The agent-loop producer emits `iteration-start` before an assistant turn; the old fake omitted it entirely.
- In the provider package, the Gladia adapter test reimplemented a shallow merge. The installed SDK recursively merges and its array behavior matters. Keep adapter event-mapping tests and `gladia.live-reconnect.test.ts`, which takes the real SDK through repeated socket drops and a finite-budget negative control. Neither needs a paid call.
- Useful controls elsewhere include small known-input/output string tests on main, the utilities retry/abort tests and the agent iteration tests on consolidation. Keep coverage at the cheapest boundary that can distinguish the bug. The audit is not a claim that every one of the 441 files or every supported platform has been manually certified.

**Leads, not demonstrated product defects:**

- On both tips, [`AnimateIn.test.ts`](../apps/desktop/src/components/common/AnimateIn.test.ts) checks initial server-rendered markup. Keep those tests. They never switch an already-mounted child from visible to exiting, so they cannot decide whether that child remains focusable during exit.
- The [PR28 Node guard](../scripts/ci/pr28-contracts.test.mjs) matches names such as `ring_alpha_fades_monotonically_after_release` in Rust source. That can detect a missing test name; it cannot report that the Rust assertion ran. Consult the native test result before drawing a conclusion about the ring.
- On consolidation, [`DotMatrixLoader.test.ts`](../apps/desktop/src/components/common/DotMatrixLoader.test.ts) checks one seed against the set of valid modes. This establishes membership, not repeatability. Remount the same seed, then use seeds known to select different modes before calling seed selection covered. The separate sixteen-cell ring-order test observes a different property.
- In the [native navigation spec](../apps/desktop/webdriver/specs/contracts.spec.ts), `clickToSettled` starts timing **after** `realClick` returns, and waits for the pathname, not for History content. Its green result is not click-to-content latency. Start from the actual click, end on route-specific content, and confirm a delayed render changes the measurement before using it as a performance gate.

### Repairs and counterexamples

| Case | Check that now distinguishes the bad implementation |
| --- | --- |
| API-key config, verbose hedge | The repo reads back the captured serialized update, including routing and favorites; the scrubber must produce exactly `this works`. An isolated `"{}"` serializer and a disabled hedge rule each failed their respective test. |
| Failed tool write; delete then send | Only the tool-result write rejects; the subsequent persisted assistant message must contain `done`. Returning early now fails. After cascade, a late send must not call message creation, even if a real DB would reject it anyway. |
| SDK retry budget | At seven generation clients, 500 and 429 cost three transport attempts, 401 costs one. The separate Groq stream does not replay a 500. Commenting out OpenAI's retry override produced **nine rather than three** on the 500 test. |
| Native review cancellation | GTK, Cocoa and both Win32 key paths delegate to one executable decision. Escape with a live ID emits exactly one cancel; another key and no pending review emit none. Reversing the guard failed both shared Rust tests. A separate GTK/X11 test drives the built pill with real key events. Changing only its adapter from Escape to F12 made it time out waiting for the cancel decision. No AppKit or Win32 key dispatch was run. |
| SVG generation | Keep drift detection; independently compare each rendered component's descendant tree, attributes and values to its own SVG. Changing one path coordinate failed that logo's behavioral comparison with the drift test excluded. |
| Cleanup and streaming | Offline controls distinguish an applied edit from an unusable reply and raw delivery. If enabled, all three live cleanup iterations must complete. AssemblyAI starts CONNECTING, reaches OPEN, and still waits for `Begin`; plain OpenAI transcription JSON no longer fabricates detailed segments. |
| Interval rejection | Observe the callback and warning as well as the absence of an unhandled rejection. A mount that never calls the callback now fails at zero rather than one call. |
| Secret history fixture | CI requires a live scanner. A redacted findings report must identify the updater rule, fixture path and adding commit; an arbitrary nonzero exit is not a detection. The clean final tree must still pass. |
| WebDriver | Require a routed control after boot. Measure the caption below Settings and hit-test the row center. The webview reached 1280×800 and 900×720; a transparent overlay over the row made `centerHitsRow` false and failed the assertion. An empty History screen remains a routing test, **not** a playback-latency measurement. |
| Skill integrity | [#313](https://github.com/maus-inc/mausVoice/pull/313#discussion_r4407462834) identified two independent inputs to the hash: path spelling and file bytes. A Linux Git checkout with `core.autocrlf=true` reported drift on **54 unchanged folders**. Preserving the original bytes (including an upstream CRLF SVG) restored 54/54 without updating a lock entry. The nested-file test uses a known SHA-256 instead of generating its own lock with the verifier. The CI workflow now also runs on Windows; that hosted result was not available locally. |

**Tool economy and steering.** Page the repository-wide endpoints once and join by PR ID; do not re-fetch the same 12,694 records for each pattern. Reuse Fallow, oxlint, i18n extraction, binding regeneration, the existing unit suites and secret scanning where they already own a rule. Put the reviewer questions in one document and the run procedure in one place. Making `AGENTS.md` longer with copies of those questions would not stop a stale review passing.
