mausVoice is developed in the open:

- [Source repository](https://github.com/maus-inc/mausVoice)
- [Releases and installers](https://github.com/maus-inc/mausVoice/releases)
- [Issue tracker](https://github.com/maus-inc/mausVoice/issues)
- [AGPLv3 license](https://github.com/maus-inc/mausVoice/blob/main/LICENCE)

Use issues for public, non-sensitive technical support and corrections. Search existing reports, add a minimal reproduction, and avoid posting credentials or private audio.

The repository lists Owie Emmanuel as maintainer. Confidential conduct reports can be sent to the email address in the Code of Conduct; sensitive incidents should not be filed as public issues. Security reports should follow any current repository security policy and private contact guidance.
