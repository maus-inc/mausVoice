The reference pages state what a control does. These guides show you where it sits and what it looks like at each stage. Every figure on these pages is a screenshot of the running desktop app in the dark theme. Nothing is redrawn for the page, and the callout below says what a capture cannot show.

<Callout title="How a figure is made">
  `apps/docs/scripts/capture-app.mjs` drives the built app through WebDriver. It
  opens the route a figure documents, waits for the element the figure is
  cropped to, closes any onboarding tip card in the way, and crops the region at
  twice the display scale. The capture runs against a database filled by
  `apps/docs/scripts/seed-guide-data.mjs`, so the figures show a plausible week
  of dictation rather than an empty first run.

  A numbered badge is drawn over a live element, so a badge cannot point at
  something the app no longer renders. Where a surface has no stable hook to
  anchor a badge to, the figure carries a caption instead of a numbered list.
</Callout>

Three conventions apply to every guide in this section.

- A badge sits on the element it describes, at that element's top-left corner, or above it when the corner is crowded.
- The number in the image and the number in the list under it always name the same thing. `scripts/check-figure-markers.mjs` fails the build when they disagree.
- Figures ship in the dark theme only. One theme per figure keeps the set small and the review diff readable.

## Regenerating the figures

The capture needs the built desktop app and a WebDriver host. Run it after a change to any surface a guide shows.

```bash
pnpm --filter docs figures            # every figure in figures.mjs
pnpm --filter docs figures -- --only home-heatmap   # one figure while iterating
pnpm --filter docs figures:check      # marker counts against the annotation lists
```

`apps/docs/scripts/figures.mjs` is the list. Each entry names the route, the element the shot is cropped to, and the badges to draw. The PNGs land in `apps/docs/public/guides/` and are committed with the script change, so a review can diff what moved.
