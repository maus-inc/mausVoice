## Find the right answer

mausVoice records speech from a global shortcut, transcribes it locally or through a provider, optionally rewrites the raw text, and delivers the result to the focused application. These guides keep those stages separate so setup and privacy decisions stay clear.

<CardGrid stagger>
  <Card title="Get a first dictation working">
    Choose your platform, finish permissions, configure Local or API
    transcription, and run a controlled test in a plain text editor.

    [Start here](getting-started/overview/)

  </Card>
  <Card title="Use every daily feature">
    Learn recording controls, the floating pill, History, Styles, Dictionary,
    insertion, language selection, and optional Assistant mode.

    [Explore daily use](using-mausvoice/app-tour/)

  </Card>
  <Card title="Configure providers correctly">
    Match transcription and generative providers to the task, manage encrypted
    API keys, or run the local Whisper sidecar.

    [Open configuration](configuration/settings-map/)

  </Card>
  <Card title="Understand the data flow">
    See exactly when audio, transcript text, style context, history, clipboard
    output, and remote output are local or network-backed.

    [Review privacy and security](privacy-security/data-flow/)

  </Card>
  <Card title="Fix a broken pipeline">
    Isolate shortcut, microphone, transcription, rewriting, persistence, and
    insertion instead of resetting everything at once.

    [Troubleshoot in order](troubleshooting/first-response/)

  </Card>
  <Card title="Build and contribute">
    Tour the React/Tauri architecture, shared packages, native pill crates,
    local sidecar, migrations, tests, docs, and releases.

    [Map the repository](development/repository-overview/)

  </Card>
</CardGrid>
