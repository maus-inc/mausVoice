# Anti-slop audit 001

Date: 2026-11-26  
Scope: PR #383 settings group-heading alignment, its verification harness, and changed comments. Existing product direction was read from `apps/desktop/DESIGN.md`. This is an audit only; no audit findings have been changed.

## Findings

1. **HIGH — R-35, verification evidence is incomplete.** The capture harness covers screenshots, geometry, themes, and browser console errors, but the delivery record does not include an element-by-element keyboard/mouse click-through of the settings navigation, search, links, selectors, and controls in each shipped theme. Screenshots and passing unit tests do not establish that those interactions work.

2. **LOW — Code Comment Skill, over-explained comment.** `apps/desktop/src/components/settings/SettingRow.test.tsx:385-390` uses six comment lines to explain the card-edge assertion. The rationale can be stated more briefly; the separate jsdom detail is useful but does not require the preceding analogy and explanation.

3. **LOW — Liveliness checklist, missing explicit Design Read and dials.** The repo has detailed product direction in `apps/desktop/DESIGN.md`, but this change has no recorded Design Read or explicit ENERGY / RHYTHM / MOTION values. The chosen alignment has a written rationale, but the antislop checklist requires the dials and Design Read to be explicit.

4. **LOW — Group action edge does not match row controls.** The Overview action links sat flush with each card's outer right edge, while the row controls ended at the inset content edge. The screenshot verifier checked heading-to-card alignment but did not measure the action edge, so it missed this inconsistency.

## Checks that looked sound within this scope

- The selected heading placement has a stated hierarchy rationale and preserves the existing card and row geometry.
- The preview harness loads the bundled font and token styles; the recorded light and dark runs report no console errors or geometry problems at 1280×900, 1100×700, and 800×600.
- No additional visual direction or assets were introduced by the card-edge alignment change.

All four findings and their dispositions are recorded in `anti-slop/follow-up-001-2026-11-26.md`.
