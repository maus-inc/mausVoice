# TAN-PARADISO (wordmark)

Place the licensed TAN-PARADISO font file here as:

- `TAN-PARADISO.ttf` (preferred)
- or `TAN-PARADISO.otf` / `TAN-PARADISO.woff2`

Then update `src/styles/fonts.css` `src:` if the extension differs.

Until the file is present, the wordmark uses `local("TAN-PARADISO")` if installed
on the OS, otherwise falls back to Plus Jakarta Sans.
