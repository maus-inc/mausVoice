Provenance for groups G23 to G27
================================

Fourth delivery, built 2026-11-08/09. Every Debian package below was resolved from
bookworm (deb.debian.org, including bookworm-security) and verified by sha256 before
extraction. Columns: package, version, cached .deb filename, sha256 of that .deb.
A copy of each package's copyright file is under LICENSES/debian/<package>/copyright.

G23 native C/C++ build: clang-14, clang++-14, llvm-14, and the GNU binutils the linker
step needs. The sysroot in system/debian12-dev-sysroot.tar.xz already carried the clang
binaries; this group vendors them into system/tools/bin with a full library closure
(libLLVM-14.so.1, libclang-cpp.so.14) and rpath $ORIGIN/../lib, plus ld/as/ar/nm/objcopy/
objdump/strip/ranlib so clang can link. Verified: clang-14 and clang++-14 compile and link
a C and a C++ program under `env -i` with only system/tools/bin on PATH.

G24 runtime data: fontconfig, the DejaVu and Liberation fonts, tzdata and the locale
source. fontconfig resolves "DejaVu Sans" from system/tools/share/fonts with
FONTCONFIG_FILE pointed at a fonts.conf the bin/ wrappers write in a temp directory at run
time, so the tree stays relocatable. tzdata provides system/tools/share/zoneinfo; locales provides
localedef plus system/tools/share/i18n, from which en_US.UTF-8 is pre-generated into
system/tools/lib/locale.

G25 browser: Chromium 156.0.8078.79 with its full shared-library closure. The binary is
system/tools/lib/chromium/chromium; bin/chromium is a launcher that sets LD_LIBRARY_PATH
to the closure. Verified headless: `--dump-dom` renders and `--screenshot` writes a PNG
under `env -i`.

G26 language runtimes: a headless OpenJDK 17 JRE (PlantUML and any JVM tool), Ruby 3.1.2
(asciidoctor), CPython 3.11 with its stdlib (binwalk, lldb), and Perl 5.36 (exiftool).
Each ships a self-locating bin/ wrapper that sets the home/library variables it needs, so
every one of them runs under `env -i`.

G27 tools: pandoc, potrace, plantuml, asciidoctor, exiftool, binwalk, lldb, mtr, hyperfine,
heaptrack, perf, the X11 capture/query tools (xdotool, scrot, xdpyinfo, xwininfo, xprop,
xlsfonts) and osslsigncode.
