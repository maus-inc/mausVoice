# Out of scope

This folder records enhancement requests the maintainers decided not to build. It exists so a
repeated request gets a linked answer instead of a fresh debate.

## How to use it

- One file per concept, named for the concept rather than the issue. `local-model-hosting.md`
  beats `issue-214.md`.
- Record the decision, the reason, the date, and links to every request that asked for it.
- When a request arrives for a concept already here, link the new issue to the record and
  explain the decision instead of reopening it.
- When a decision is reversed, update the record with a dated correction and the reason. Do not
  delete the history.

The triage rules that write these files are in `AGENTS.md`, under triage and briefs.
